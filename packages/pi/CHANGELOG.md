# Changelog

## 0.1.3

Depends on undohaven-core 0.1.16. No pi behavior change in this release.

## 0.1.2

Depends on undohaven-core 0.1.15. File snapshots use the padded manifest and the padded byte total.

## 0.1.1

Depends on undohaven-core 0.1.14. No pi snapshot behavior change in this release.

## 0.1.0

Local encrypted snapshots of pi sessions, settings, and extensions, with per-file restore, a path exclude toggle, and a safety snapshot before session-file changes. Pro accounts can upload the same ciphertext to the existing UndoHaven service.
